# Inbox: card proposals

Agents drop short proposals here when something they built may deserve a card but they are not
sure, or have no time to write it. One file per proposal: `<yyyy-mm-dd>-<slug>.md`, 10 lines max:

```markdown
# <Proposed card title>
- Why it matters: <one line>
- What we built: <repo, PR or commit links>
- Best-in-class references: <2-3 URLs>
- Proposed by: <agent / session>, <date>
```

Triage (by the orchestrator or the next veille agent): promote to `cards/` or delete. A proposal
older than 30 days that nobody promoted is deleted.
